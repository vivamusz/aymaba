# AYMABA — главный сайт

Главная страница AYMABA для специалистов (ABA, логопеды, дефектологи): меню и плитки
«Конструктор», «Коммуникатор», «Библиотека карточек», «Наборы для печати», тарифы (предварительно)
и юридические документы. Обычный статический сайт: HTML + CSS + JS, **без сборки**.
Работает на GitHub Pages (ветка `main`, корень).

Сайт: https://vivamusz.github.io/aymaba/

## Структура

```
index.html            главная страница (шапка, разделы, тарифы, подвал)
library.html          Библиотека карточек + печать на одной странице (как upecs.ru/#library)
oferta.html           Публичная оферта      ┐ создаются скриптом
terms.html            Условия использования ├ tools/build_legal.py,
faq.html              Частые вопросы        ┘ вручную не править
assets/config.js      ссылки на разделы (CONSTRUCTOR_URL, COMMUNICATOR_URL, VERB_SET_URL)
assets/i18n.js        ВСЕ тексты сайта на русском (ru) и казахском (kk)
assets/app.js         переключатель языка, мобильное меню, подстановка ссылок
assets/style.css      оформление всех страниц (цвета — в :root в начале файла)
assets/library.js     интерфейс страницы library.html: разделы, выбор карточек, «Мой набор», рамки
assets/library.css    оформление library.html (меню слева, панель «Мой набор» справа, @media print)
assets/sheets.js      геометрия листов 9/7/5, отрисовка, PDF (pdf-lib), печать, Word (.docx)
assets/pecs/          template.png (9 см), template-5.png (5 см), template-7.png (7 см, ВРЕМЕННЫЙ)
assets/fonts/DejaVuSans-Bold.ttf  шрифт подписей (не заменять)
assets/vendor/        pdf-lib 1.17.1, @pdf-lib/fontkit 1.1.1, fflate 0.8.2 (локальные копии, без CDN)

assets/favicon.svg    значок сайта
cards/<id>.webp       веб-версии карточек 512×512 (только .webp, без файлов для печати)
data/cards.json       список карточек: categories [{num, ru}], cards [{id, ru, cat}]
tools/legal_src/*.docx исходники документов (оферта, условия, FAQ)
tools/build_legal.py  docx → html (+ обновляет шапку/подвал в library.html)
tools/build_cards.py  собирает cards/ и data/cards.json из пакетов /workspace/aymaba_web и /workspace/aymaba_verbs68
tools/make_template7.py  рисует временный template-7.png в стиле template.png
tools/shots.py        скриншоты для проверки (playwright + chrome)
.nojekyll             чтобы GitHub Pages отдавал файлы как есть
```

## Как поменять текст

1. Откройте `assets/i18n.js`. Там два блока: `ru` и `kk`.
2. Найдите нужный ключ (например `"hero.title"`) и поменяйте строку **в обоих языках**.
3. В `index.html` у элемента стоит `data-i18n="hero.title"` — так он связан с текстом.
   Новый текст: добавьте ключ в `ru` и `kk` и элемент с `data-i18n="новый.ключ"`.

Язык выбирается кнопками KZ / RU, запоминается в браузере; можно открыть сразу `?lang=kk`.

## Ссылки и VERB_SET_URL

Все ссылки — в `assets/config.js`:

- `CONSTRUCTOR_URL` — ABA-конструктор;
- `COMMUNICATOR_URL` — коммуникатор на пиктограммах;
- `VERB_SET_URL` — страница покупки набора глаголов.
  Если поставить `"#"`, кнопка «Купить» станет серой с надписью «Скоро».

## Библиотека карточек

- Карточки: 92 глагола (пакеты ПЕКС КАРТОЧКИ, 68 + 24) + 541 карточка (пакет АВА карточки), всего 633, 26 категорий.
- Обновить карточки: `python tools/build_cards.py [папка_aymaba_web] [папки глаголов...]`
  — копирует только `web/<id>.webp` и пересобирает `data/cards.json`.
- Названия показываются **только на русском**. Казахские поля (`kk`, `category_kk`) в пакетах —
  непроверенные черновики, скрипт их не переносит. После проверки носителем языка их можно
  добавить в `data/cards.json` и вывести в `assets/library.js`.
- Для печати используются `print/<id>.webp` (1063 px). Папка ~43 МБ — для GitHub Pages это нормально (лимит 1 ГБ).

## Печать (library.html)

Одна страница: слева меню — **Библиотека**, **Мой набор**, **Настройки печати**, **Справка** (адреса `#library`, `#set`, `#settings`, `#help`);
справа — «Мой набор» (миниатюры, счётчик, кнопки вывода). На телефоне меню внизу экрана.

- Нажатие на карточку добавляет её в набор, повторное — убирает. Можно добавить свои фото (JPG/PNG/WebP) с телефона или компьютера.
- От 1 до 60 картинок. Пустые рамки остаются пустыми. Лимит 60 не повышать (`MAX` в sheets.js).
- В «Моём наборе»: нажать на рамку — заменить картинку (с устройства / из библиотеки / убрать);
  перетащить на другую рамку — поменять местами; двигать картинку внутри рамки пальцем или мышкой; − и + — размер.
- Размер: 9 см (6 на листе), 7 см (9 на листе), 5 см (20 на листе).
- Подпись: «Без подписи» (фото на всю рамку), «Қазақша», «Русский». В PDF идёт только выбранный язык, шрифт DejaVu Sans Bold.
  Русская подпись берётся из названия карточки (можно поправить). **Казахская подпись по умолчанию пустая** —
  казахские поля карточек непроверенные черновики, их не подставляем и не переводим машинно; слово вписывает специалист.
- Вывод:
  1. **Печать** — окно печати браузера (`window.print()`), каждый лист на отдельной странице A4 в точном размере,
     поля 0. В окне печати выбрать масштаб 100% / «Фактический размер». Подходит для принтера, Microsoft Print to PDF, Adobe PDF, XPS, OneNote.
  2. **Скачать PDF** — по одному PDF на лист («ПЕЧАТЬ 9 см 1.pdf»); несколько листов — одним zip-архивом. PDF без пароля.
  3. **Скачать Word (.docx)** — каждый лист отдельной страницей A4 картинкой в точном размере, без полей.
- Всё делается в браузере, на сервер ничего не отправляется. Выбранные карточки библиотеки, подписи и настройки
  запоминаются в браузере (localStorage); **свои фото не запоминаются** — после перезагрузки их нужно добавить снова.

Не менять: геометрию рамок в `assets/sheets.js`, файлы `template.png` и `template-5.png`, шрифт `DejaVuSans-Bold.ttf`.

**template-7.png — временный.** Оригинального шаблона 7 см нет, поэтому он нарисован скриптом `tools/make_template7.py`
в точности в стиле `template.png` (тот же синий цвет, толщина 24 px, скругление). Важно: три рамки ровно по 7 см в ширину A4
(21 см) не помещаются вместе с обводкой, поэтому окно рамки ≈ 6,4 см (760 px при 300 dpi), лист — A4, 9 рамок.
Когда будет настоящий шаблон — положить его вместо `assets/pecs/template-7.png` и поправить координаты `SHEETS["7"]` в `assets/sheets.js`.

## Юридические документы

Правьте `.docx` в `tools/legal_src/`, затем:

```
pip install python-docx
python tools/build_legal.py
```

Скрипт берёт шапку и подвал из `index.html` (между `<!--HEADER-->` / `<!--FOOTER-->`),
подсвечивает незаполненные места `[БИН]`, `[email]` и т.п. и заменяет «ABA/PECS» на
«ABA и пиктограммы» (список замен — `REPLACE` в скрипте). Если поменяли шапку или подвал
в `index.html`, тоже запустите скрипт, чтобы документы обновились.

## Правила текстов

- Не писать «PECS» в названиях и рекламе — говорим «пиктограммы», «коммуникатор на пиктограммах».
- Не обещать, что ребёнок заговорит, и не обещать результат.
- Никаких выдуманных отзывов, цифр и «довольных клиентов».
- Тарифы помечены как предварительные; оплаты на сайте пока нет.

## Что пока заглушка

- template-7.png — временный (см. «Печать»).
- Печать пока открыта всем, без подписки.
- «Другие наборы» — «Скоро».
- Тарифы — предварительные, без оплаты и входа (GitHub Pages не умеет закрывать платные разделы).
- В документах не заполнены реквизиты: `[БИН]`, `[сайт]`, `[email]`, `[телефон]` и др.
