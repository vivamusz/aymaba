# AYMABA — главный сайт

Главная страница AYMABA для специалистов (ABA, логопеды, дефектологи): меню и плитки
«Конструктор», «Коммуникатор», «Библиотека карточек», «Наборы для печати», тарифы (предварительно)
и юридические документы. Обычный статический сайт: HTML + CSS + JS, **без сборки**.
Работает на GitHub Pages (ветка `main`, корень).

Сайт: https://vivamusz.github.io/aymaba/

## Структура

```
index.html            главная страница (шапка, разделы, тарифы, подвал)
library.html          Библиотека карточек (поиск, фильтр по темам, просмотр крупно)
oferta.html           Публичная оферта      ┐ создаются скриптом
terms.html            Условия использования ├ tools/build_legal.py,
faq.html              Частые вопросы        ┘ вручную не править
assets/config.js      ссылки на разделы (CONSTRUCTOR_URL, COMMUNICATOR_URL, VERB_SET_URL)
assets/i18n.js        ВСЕ тексты сайта на русском (ru) и казахском (kk)
assets/app.js         переключатель языка, мобильное меню, подстановка ссылок
assets/style.css      оформление всех страниц (цвета — в :root в начале файла)
assets/library.js     логика библиотеки карточек
assets/favicon.svg    значок сайта
cards/<id>.webp       веб-версии карточек 512×512 (только .webp, без файлов для печати)
data/cards.json       список карточек: categories [{num, ru}], cards [{id, ru, cat}]
tools/legal_src/*.docx исходники документов (оферта, условия, FAQ)
tools/build_legal.py  docx → html (+ обновляет шапку/подвал в library.html)
tools/build_cards.py  собирает cards/ и data/cards.json из пакетов /workspace/aymaba_web и /workspace/aymaba_verbs68
tools/shots.py        скриншоты для проверки (playwright + chrome)
.nojekyll             чтобы GitHub Pages отдавал файлы как есть
```

## Как поменять текст

1. Откройте `assets/i18n.js`. Там два блока: `ru` и `kk`.
2. Найдите нужный ключ (например `"hero.title"`) и поменяйте строку **в обоих языках**.
3. В `index.html` у элемента стоит `data-i18n="hero.title"` — так он связан с текстом.
   Новый текст: добавьте ключ в `ru` и `kk` и элемент с `data-i18n="новый.ключ"`.

Язык выбирается кнопками KZ / RU, запоминается в браузере; можно открыть сразу `?lang=kk`.

## Ссылки и VERB_SET_URL

Все ссылки — в `assets/config.js`:

- `CONSTRUCTOR_URL` — ABA-конструктор;
- `COMMUNICATOR_URL` — коммуникатор на пиктограммах;
- `VERB_SET_URL` — страница покупки набора глаголов. **Сейчас стоит `"#"` (TODO).**
  Пока там `"#"`, кнопка «Купить» показывается серой с надписью «Скоро».
  Вставьте настоящий адрес — кнопка заработает сама.

## Библиотека карточек

- Карточки: 92 глагола (пакеты ПЕКС КАРТОЧКИ, 68 + 24) + 541 карточка (пакет АВА карточки), всего 633, 26 категорий.
- Обновить карточки: `python tools/build_cards.py [папка_aymaba_web] [папки глаголов...]`
  — копирует только `web/<id>.webp` и пересобирает `data/cards.json`.
- Названия показываются **только на русском**. Казахские поля (`kk`, `category_kk`) в пакетах —
  непроверенные черновики, скрипт их не переносит. После проверки носителем языка их можно
  добавить в `data/cards.json` и вывести в `assets/library.js`.
- Полноразмерные файлы для печати (`full/`) на сайт не выкладываются: печать будет по подписке.
  На странице стоит пометка «Печать в полном размере — по подписке (скоро)».

## Юридические документы

Правьте `.docx` в `tools/legal_src/`, затем:

```
pip install python-docx
python tools/build_legal.py
```

Скрипт берёт шапку и подвал из `index.html` (между `<!--HEADER-->` / `<!--FOOTER-->`),
подсвечивает незаполненные места `[БИН]`, `[email]` и т.п. и заменяет «ABA/PECS» на
«ABA и пиктограммы» (список замен — `REPLACE` в скрипте). Если поменяли шапку или подвал
в `index.html`, тоже запустите скрипт, чтобы документы обновились.

## Правила текстов

- Не писать «PECS» в названиях и рекламе — говорим «пиктограммы», «коммуникатор на пиктограммах».
- Не обещать, что ребёнок заговорит, и не обещать результат.
- Никаких выдуманных отзывов, цифр и «довольных клиентов».
- Тарифы помечены как предварительные; оплаты на сайте пока нет.

## Что пока заглушка

- Библиотека: только просмотр и поиск; печать в полном размере — «скоро» (по подписке).
- `VERB_SET_URL = "#"` — кнопка «Купить» неактивна.
- «Другие наборы» — «Скоро».
- Тарифы — предварительные, без оплаты и входа (GitHub Pages не умеет закрывать платные разделы).
- В документах не заполнены реквизиты: `[БИН]`, `[сайт]`, `[email]`, `[телефон]` и др.
