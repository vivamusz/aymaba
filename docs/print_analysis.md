# Страница «Библиотека и печать» — разбор и план

Цель пользователя: специалист открыл библиотеку → выбрал размер → накликал карточки из разных тем → сразу печать.
Это главная страница сайта, поэтому всё должно быть просто.

## С чем сравнивали

- **upecs.ru** (код: github.com/olluorg/upecs) — образец структуры. Есть: меню слева (Библиотека, Мой набор, Мои наборы,
  Настройки печати, Документация), «Мой набор» из любых категорий с запоминанием, именованные наборы (переименовать,
  копия, переключение, ссылка для коллеги), сетка 2×2/3×3/4×4, книжная/альбомная, подписи вкл/выкл, линии реза с вылетами,
  CMYK, предпросмотр PDF, своя карточка с фото (хранится в IndexedDB), установка на телефон (PWA), коммуникативная доска, озвучка.
- Типичные зарубежные конструкторы карточек на пиктограммах (Boardmaker, LessonPix, ARASAAC и похожие): общий поиск по всей
  библиотеке, копии одной карточки, размеры «на лист», подписи сверху/снизу и размер шрифта, рамки по цвету темы,
  готовые шаблоны (расписание, последовательности), сохранение и обмен наборами.

## Что сделано сейчас (ветка wip-print2)

1. **Порядок работы на экране:** шаг 1 — размер (Карточки 9 / 7 / 5 см, Сюжетные A5 / A6 / A4), шаг 2 — отметить карточки.
   Размер можно поменять после выбора — набор не теряется.
2. **Итог всегда виден:** «12 карточек · 9 см — 2 листа A4» — над библиотекой, в панели справа, на телефоне в нижней полоске «К печати ›».
3. **Поиск по всем темам сразу** (ё = е): набрал «яблоко» — нажал — карточка в наборе.
4. **Готовые наборы одной кнопкой:** глаголы, еда, фрукты, овощи, домашние животные; плюс «Добавить всю тему «…»».
   Лимит 60 сохранён: из 92 глаголов добавится 60, остальные — вторым набором (сообщение об этом показывается).
5. **Копии:** кнопка «+1» у рамки и в мини-листе справа; на карточке в библиотеке видно «×2», «×3».
6. **Мои наборы:** новый набор, переименовать, копия, удалить, переключение; **ссылка** на набор — коллега открывает тот же набор
   (размер, подписи, копии, сдвиги). Свои фото в ссылку не входят.
7. **Живой лист справа:** мини-листы по страницам с тем же числом столбцов, что на бумаге; пустые места видны.
8. **Линии реза** (переключатель в настройках; у сюжетных — всегда).
9. **Просмотр PDF** перед печатью (во вкладке браузера).
10. **Печать в натуральную величину:** любой лист — настоящий A4, шаблон по центру 1:1 (PDF, печать, Word).
    Подсказка у кнопок: «Печатайте в реальном размере (100%), без «по размеру страницы»».
11. **Печать только из полных файлов** print/<id>.webp (1063 px); маленькие превью — только для выбора.
12. **Сюжетные A5 / A6 / A4** на обычном A4: прямоугольные рамки в стиле шаблона 9 см, отступ 5 мм от линии реза,
    картинка вписывается целиком без искажений, есть поворот ⟲, сдвиг и −/+. Подходят и наши карточки, и свои скачанные картинки.
13. **Простая защита картинок:** нет меню «Сохранить картинку» (правая кнопка / долгое нажатие), картинки нельзя вытащить мышкой;
    кнопки «скачать карточку» нет. Перетаскивание карточки в набор и рамок между собой работает.

## Позже / на решение пользователя

- **7×7:** сейчас временный шаблон 3×3 (окно ≈ 6,4 см). Вариант ПЕКС КАРТОЧКИ: **8 на A4 (2×4), ровно 7 см**, поля ≈ 8 мм — честный размер. Нужно решение.
- **5 см:** шаблон пользователя шириной 207,5 мм — на A4 до края остаётся ≈ 1,2 мм. Многие принтеры не печатают ближе 3–4 мм от края,
  крайние рамки могут обрезаться. Геометрию шаблона не меняли (запрет ТЗ); можно сделать вариант с уменьшенными полями листа, если разрешите.
- Подписи: оба языка сразу, размер шрифта, подпись сверху/снизу (казахская — только после проверки носителем).
- Цвет рамки по теме / без рамки; альбомная ориентация для квадратных карточек.
- Свои фото сохранять между визитами (IndexedDB), как в upecs.
- Установка на телефон как приложение (PWA).
- Снятие лимита 60 для готовых наборов (сейчас 60 по исходному ТЗ).
- Настоящая защита карточек — только с подпиской и своим сервером (сейчас файлы карточек на GitHub Pages открыты).
